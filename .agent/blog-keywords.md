# Blog Keyword Bank Rules

## Purpose
- Use this file as the master keyword bank for blog generation and site-wide SEO copy
- The keyword bank may contain up to 500 US-focused keywords for chauffeur, limo, black car, and airport transfer intent
- Group keywords by cluster so each blog is built around one clear topical league
- If the user provides a flat list without clusters, treat it as a raw keyword pool and infer clusters during blog planning
- Treat this file as the primary keyword source for the full website, not blogs only
- These keywords are the approved main SEO terms and should be reused across service pages, airport pages, service-area pages, core pages, metadata, internal links, and other search-facing copy when relevant

## Brand and Geo Guardrails
- Brand: ALAR Chauffeur Service
- Primary geo: New Jersey, New York, Connecticut, Pennsylvania, Tri-State, Edison NJ
- Secondary geo: California, Nevada, Washington
- Primary airports: JFK, LGA, EWR, HPN, TEB, PHL, BDL, LAX, LAS, SEA
- Prefer reserved chauffeur / black car / airport car service language
- Do not target Uber, Lyft, taxi franchise, or self-drive rental keywords as primary offers

## Selection Rules
- For each new blog, select 4 to 5 keywords from one cluster only
- Use exactly 1 primary keyword and 3 to 4 secondary keywords from the same cluster
- Keep all selected keywords aligned to the same intent, topic, and search journey
- Do not mix unrelated clusters in one blog because topical focus and SEO depth will break down
- Prefer keywords that have not been used yet
- Do not reuse the same primary keyword again and again
- Do not reuse the exact same keyword combination in consecutive blogs
- Rotate keywords across the cluster before repeating a previously used primary keyword
- If a cluster has limited unused keywords left, reuse only after checking `/.agent/blog-keyword-usage.md`
- When only a flat keyword list is available, first identify 4 to 5 closely related keywords from that list and treat them as the temporary cluster for that blog

## Writing Rules
- Keep one primary keyword for the article
- Use the remaining 3 to 4 keywords as natural supporting terms
- Keep the article centered on one cluster so the post strengthens topical authority
- Use related keywords naturally in H2, H3, FAQ, examples, and body copy
- Do not force every keyword into headings if it harms readability
- Keep all keyword choices strictly US-focused, with Tri-State preference when the topic is local

## Site Wide Usage Rules
- Use this file as the first reference for SEO keyword targeting across the entire site
- Reuse relevant keywords naturally in homepage copy, service copy, airport pages, service-area pages, blog pages, CTAs, image alt text, and internal anchor text
- Keep keyword usage page-specific so the chosen terms match the page intent and offer
- Do not stuff multiple unrelated keywords into the same page just because they exist in the bank
- Keep all keyword usage human-readable, commercially relevant, and US-focused

## Workflow
1. Review the clusters in this file, or the raw keyword pool if the user pasted a flat list
2. Check `/.agent/blog-keyword-usage.md` for recently used keywords
3. Pick one cluster with low recent usage, or infer one temporary cluster from related raw keywords
4. Select 1 unused or least-used primary keyword
5. Select 3 to 4 supporting keywords from the same cluster
6. Generate the blog around that cluster only
7. Append the final usage entry to `/.agent/blog-keyword-usage.md`
